MODULE 7 — ARRAYS
Collections of data — the backbone of PHP applications
MODULE 7
What is an Array? An array is a special variable that holds multiple values under one name.
💡 Why arrays? They allow you to group related data, iterate over collections, and build complex data structures. Without arrays, web apps would be much harder to manage.

Creating Arrays — 3 Ways

$arr = [1,2,3];
$arr = array(1,2,3);
$arr = []; $arr[] = "first";

Key Facts

  • Hold any data type
  • Indexed start at 0
  • Dynamic size
  • Use print_r() to debug
